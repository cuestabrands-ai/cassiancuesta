## DESIGN RULES (read first, never deviate)

**Global:**
- Background: `#F8F9FF` (all pages, body + html)
- Primary text: `#1E1B4B`
- Secondary text: `#6B7280`
- Muted text: `#9CA3AF`
- Cards: `white` bg, `1.5px solid #F1F5F9` border, `border-radius: 20px`, `box-shadow: 0 2px 12px rgba(0,0,0,.05)`
- Card hover: `border-color` → accent border color, shadow with accent tint, `translateY(-4px) scale(1.02)`
- Card tap: `scale(0.94)`
- Font: `'Nunito', system-ui, sans-serif` — 700/800/900 weights only
- NO dark backgrounds, NO glass morphism, NO backdrop-filter blur on cards, NO gradient text

**Header (every page):**
- Background: `linear-gradient(180deg, {ACCENT_BG} 0%, #F8F9FF 100%)`
- Bottom border: `1px solid {ACCENT_BORDER}`
- Padding: `calc(16px + env(safe-area-inset-top)) 16px 16px`
- Page emoji or icon: large (48–56px), floating animation
- Page title: `font-size: 22px; font-weight: 900; color: {ACCENT_DARK}`
- Tagline: `font-size: 13px; font-weight: 700; color: {ACCENT}`
